# 🎮 Number Guessing Game (C++)

A console-based Number Guessing Game developed in C++ as part of my **Codveda Technologies C/C++ Development Internship (Level 1)**.

This project demonstrates fundamental C++ programming concepts, user input validation, modular programming, and Git version control through incremental development.

---

## ✨ Features

- 🎯 Three difficulty levels
  - Easy (1–50)
  - Medium (1–100)
  - Hard (1–500)

- 🎲 Random number generation

- 🔢 Maximum 6 attempts

- 📈 Too High / Too Low hints

- ✅ Robust input validation

- 🚫 Rejects invalid and non-numeric input

- 🚪 Quit the game anytime by entering **0**

- ❓ Quit confirmation before exiting

- 🔄 Play Again option

- ⭐ Performance feedback after winning

- 🧩 Modular function-based architecture

---

## 🚀 How to Run

1. Clone this repository

```bash
git clone https://github.com/IftakherEmon/codveda-cpp-number-guessing-game.git
```

2. Open the project

3. Compile

```bash
g++ main.cpp -o game
```

4. Run

```bash
./game
```
